**001 在文章每段段首加两个中文(全角)空格**

(。_。)很多文本工具里换行起段都是默认顶格，总之在中文写作场景需要段首空格很不方便，传给ai帮忙处理又不放心，所以自己简单敲了一段。

(・∀・*)试验过①空行②特殊标点符号(~、「」、...)③UTF-8包含的生僻字之类 都是可以不受影响的。

(・-・*)只是在Windows系统自用的小东西。很简单粗陋的。

用法：

（1）在ori_text.txt里放入原文本。只能处理不带格式的纯文本。要改文件名的话就把代码里inputFile的名字也改了，不过不建议走中文路径。

（2）在任意IDE里打开并运行cpp代码。

（3）打开生成的ope_text.txt，得到的就是处理好的文本。
